# Instrução para o Claude Code

Trabalhe nesta pasta como um projeto de design automatizado para Instagram.

1. Leia integralmente `README.md`, `conteudo.json` e `create_carousel.js`.
2. Faça mudanças de texto, tema e cor principalmente em `conteudo.json`.
3. Preserve nove cards, a ordem dos arquivos, o formato 1080 × 1350 px, as margens, a hierarquia tipográfica e a assinatura `MENTE MULHER ESTOICA`.
4. Mantenha uma ideia principal por card e evite blocos longos.
5. Não trate o conteúdo como confissão pessoal da autora, salvo pedido explícito.
6. Não invente dados, estudos ou citações. Quando houver afirmação factual, verifique a fonte.
7. Execute `npm install` e `npm run gerar`.
8. Abra e inspecione `saida/preview.png`; corrija texto cortado, linhas apertadas, erro de português, inconsistência de cor ou quebra inadequada.
9. Execute `npm run validar` antes de concluir.
10. Compacte somente os nove cards finais, na ordem, em `carrossel-pronto.zip`; não inclua `preview.png`.
