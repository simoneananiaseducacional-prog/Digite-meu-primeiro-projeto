# Carrossel — Viés de confirmação

Carrossel de nove cards criado em Node.js com a biblioteca Sharp para a identidade visual da Mente Mulher Estoica.

## Estrutura editorial

1. Capa
2. Inimigo
3. História
4. Dados
5. Confissão editorial
6. Contraste
7. Passo a passo
8. Demonstração
9. Encerramento

A mesma tese é apresentada por sete ângulos diferentes, sem transformar os cards em blocos longos de texto.

## Uso

```bash
npm install
npm run gerar
npm run validar
```

Os nove PNGs em 1080 × 1350 e a prévia geral são gerados dentro de `saida/`.

## Precisão conceitual

O projeto evita a formulação absoluta “a mente não busca a verdade”. O viés de confirmação é apresentado como uma tendência de buscar ou interpretar evidências de maneira favorável a crenças existentes. As referências completas estão em `REFERENCIAS.md`.
