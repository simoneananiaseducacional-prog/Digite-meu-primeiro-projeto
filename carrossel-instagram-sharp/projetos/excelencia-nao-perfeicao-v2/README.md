# Carrossel — Excelência não é perfeição

Carrossel de nove cards da Mente Mulher Estoica.

## Estrutura editorial

1. Capa
2. Inimigo
3. História
4. Dados
5. Confissão editorial
6. Contraste
7. Passo a passo
8. Demonstração
9. Encerramento

A publicação parte de uma única ideia central — **Excelência não é perfeição. É fazer bem o que depende de você.** — e a reapresenta por sete ângulos, sem repetir a mesma formulação.

## Padrão visual

Este projeto reutiliza o mesmo motor visual do carrossel `vies-confirmacao`, preservando a identidade já validada: preto, vinho, marfim e taupe; textura sutil; serifada + sans; números fantasma; diagramas; composições diferentes em cada card; assinatura `MENTE MULHER ESTOICA`.

## Precisão dos dados

O card de dados se baseia em Hill & Curran (2016), meta-análise de 43 estudos, N = 9.838, sobre perfeccionismo multidimensional e burnout.
