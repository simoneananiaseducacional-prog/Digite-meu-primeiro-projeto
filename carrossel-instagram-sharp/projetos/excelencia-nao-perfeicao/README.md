# Carrossel — Excelência não é perfeição

Modelo minimalista da Mente Mulher Estoica, inspirado em leitura rápida para Instagram, sem replicar identidade de terceiros.

## Formato
- 9 cards
- 1080 × 1350 px
- Fundo preto
- Branco + laranja como contraste
- Uma ideia central trabalhada por 7 ângulos: inimigo, história, dados, confissão editorial, contraste, passo a passo e demonstração

## Gerar
```bash
npm run gerar
```

Saída em `saida/`.
