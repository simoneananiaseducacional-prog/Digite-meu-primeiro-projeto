# Prompts de referência · Escrita mais humana e clara

Prompts para revisar e melhorar textos: deixá-los mais claros, com ritmo e soando
como uma pessoa real. Guardados como **referência e inspiração**, para uso pessoal.

## Fonte e créditos

> Carrossel de **@orodolfosouza** (Rodolfo Souza · Instagram), transcrito para consulta.
> **Autoria de terceiros.** Não revender nem republicar como conteúdo próprio.
> Ótimos para passar nos seus próprios textos antes de publicar, mantendo a voz da marca.

Em cada prompt, cole o seu texto onde está `[cole seu texto]`.

---

## 1. Filtro de Clareza

```
Simplifique este texto sem perder a mensagem. Use frases curtas, palavras comuns e deixe tudo fácil de entender.

Texto: [cole seu texto]
```

## 2. Ritmo de Leitura

```
Melhore o ritmo deste texto. Varie o tamanho das frases, corte excessos e faça a leitura fluir melhor em voz alta.

Texto: [cole seu texto]
```

## 3. Mais Personalidade

```
Adicione mais personalidade a este texto sem mudar a mensagem principal. Deixe mais próximo, interessante e vivo.

Texto: [cole seu texto]
```

## 4. Soar Humano

```
Reescreva este texto para soar humano, claro e natural. Use linguagem simples, frases variadas e pequenos ajustes de ritmo.

Texto: [cole seu texto]
```

## 5. Teste da Pessoa Real

```
Edite este texto para soar como algo que uma pessoa real diria. Remova partes genéricas, artificiais ou polidas demais.

Texto: [cole seu texto]
```
