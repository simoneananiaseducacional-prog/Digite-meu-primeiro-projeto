# Prompts de referência · Aprendizado e Pensamento

Coleção de prompts encontrados no Instagram e guardados aqui como **referência e
inspiração** de estudo. Servem para uso pessoal, não como produto.

## Fonte e créditos

> Carrossel de **@orodolfosouza** (Instagram), transcrito para consulta.
> **Autoria de terceiros.** Não revender nem republicar como conteúdo próprio.
> Se algum desses prompts inspirar um conteúdo da marca, reescreva com palavras
> próprias e adapte à voz Mente Mulher Estoica.

Substitua o que está entre colchetes `[ ]` pelo seu tema.

---

## 1. Entenda qualquer assunto a fundo

```
Quero entender [tema] com profundidade. Explique o conceito com analogias inteligentes, aplicações reais, contrapontos e perspectivas diferentes. Depois, teste meu entendimento com perguntas de nível avançado.
```

## 2. Aprenda qualquer habilidade gastando pouco

```
Assuma o papel de alguém que domina [habilidade] há 20 anos. Mostre o caminho que levou até esse nível e monte um plano diário, prático e acelerado, usando apenas recursos gratuitos ou de baixo custo.
```

## 3. Destrave bloqueios mentais

```
Tenho dificuldade com [problema pessoal: procrastinação, burnout, medo etc.]. Analise isso como um cientista cognitivo. Identifique as causas, os padrões de comportamento e crie um plano de hábitos para reduzir esse bloqueio.
```

## 4. Transforme confusão em clareza

```
Não estou entendendo [conceito complexo]. Explique passo a passo usando imagens mentais, exemplos concretos e comparações simples. Depois, crie um atalho mental para eu lembrar disso com facilidade.
```

## 5. Tenha uma visão de nível acadêmico

```
Ensine [tema] como se eu estivesse me preparando para um mestrado ou doutorado. Comece pelos primeiros princípios, explique as teorias centrais, traga o contexto histórico e indique livros, artigos e autores para aprofundar.
```

## 6. Construa modelos mentais úteis

```
Quero dominar [habilidade/tema]. Crie um modelo mental ou estrutura de decisão que simplifique como abordar, avaliar e melhorar meu desempenho ao longo do tempo.
```

## 7. Faça um upgrade mental em 30 dias

```
Monte um programa de 30 dias para melhorar meu pensamento, aprendizado e memória. Inclua rotinas cognitivas, exercícios de reflexão, leituras úteis, técnicas de memorização e hábitos de descanso. Mantenha tudo prático e viável.
```
