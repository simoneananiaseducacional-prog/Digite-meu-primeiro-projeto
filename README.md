## CREI Slide System

A pasta `slides/` contém o padrão mestre para criação das apresentações do CREI Pouso Alegre.

Arquivos principais:
- `slides/CREI_SLIDE_SYSTEM.md` — diretriz pedagógica, visual e de oratória.
- `slides/crei_slide_system.json` — regras estruturadas, paleta, tipografia e critérios de qualidade.
- `slides/crei_slide_prompt_builder.py` — gerador de briefings e prompts para novos slides.

Princípio central do sistema:

> **O slide mostra; a formadora explica.**

O padrão prioriza slides didáticos, ilustrativos, interativos, sofisticados, com estética editorial/cinematográfica, identidade azul-marinho + laranja + off-white e rigor técnico nas referências de Educação Especial Inclusiva.
