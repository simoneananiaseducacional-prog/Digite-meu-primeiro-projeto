# Materiais de Educação Especial Inclusiva

Este repositório reúne materiais de estudo, documentos, casos fictícios e recursos sobre Educação Especial Inclusiva, PDI, AEE, Sala de Recursos e Professor de Apoio.

## Conteúdos
- Documentos orientadores
- Casos fictícios para formação
- Guias pedagógicos
- Recursos em HTML

## CREI Slide System

A pasta `slides/` contém o padrão mestre para criação das apresentações do CREI Pouso Alegre.

Arquivos principais:
- `slides/CREI_SLIDE_SYSTEM.md` — diretriz pedagógica, visual e de oratória.
- `slides/crei_slide_system.json` — regras estruturadas, paleta, tipografia e critérios de qualidade.
- `slides/crei_slide_prompt_builder.py` — gerador de briefings e prompts para novos slides.

Princípio central do sistema:

> **O slide mostra; a formadora explica.**

O padrão prioriza slides didáticos, ilustrativos, interativos, sofisticados, com estética editorial/cinematográfica, identidade azul-marinho + laranja + off-white e rigor técnico nas referências de Educação Especial Inclusiva.

## Skills

A pasta `skills/` reúne instruções reutilizáveis para agentes e fluxos de trabalho.

- `skills/cead-auditor-ava/SKILL.md` — auditoria pedagógica e técnica do AVA.
- `skills/comandos-gpt/SKILL.md` — biblioteca com 99 modos acionados por prefixos como `/human`, `/critic`, `/study`, `/research`, `/decision`, `/instagram`, `/reels`, `/risk` e `/review`.

Os comandos podem ser combinados. Exemplo:

`/research /critic /compare: analise estas opções e indique a mais consistente.`
